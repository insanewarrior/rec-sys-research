%   3.2 Three intensity injections, each gated by one learnable scalar
%       lambda per layer (initialised to 1.0):
%         Add: softmax( Q K^T / sqrt(d) + lambda * w_k ) V         (2)
%              -> additive logit bias from key-position intensity.
%         Mul: softmax( (Q K^T / sqrt(d)) * (1 + lambda*(w_k-1)) ) V (3)

%         Val: ( softmax(Q K^T / sqrt(d)) * (1 + lambda*(w_k-1)) ) V (4)
%              -> post-softmax key reweighting; preserves attention as
%              a probability distribution but reweights how much each
%              key's value contributes. NEW SEMANTICS — note in caption
%              that this is a breaking change vs. earlier IA-SASRec
%              drafts (the old Val multiplied the post-attention
%              context by query-position intensity and could not
%              reorder candidates; see ia_sasrec.md).
%
%   3.3 The lambda escape hatch (load-bearing for §6 mechanism story):
%       At lambda=0 every variant collapses *exactly* to SASRec, so a
%       fair learner that finds intensity uninformative should drive
%       lambda toward 0 and recover the baseline. This is the
%       prediction we test in §6.
%
%   3.4 Intensity normalisation (lift ia_sasrec.md §4):
